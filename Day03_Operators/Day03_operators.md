# 📘 Day 3: Operators

## **Concepts**
- **Arithmetic Operators**: `+`, `-`, `*`, `/`, `%`, `//`, `**`
- **Comparison Operators**: `==`, `!=`, `>`, `<`, `>=`, `<=`
- **Assignment Operators**: `=`, `+=`, `-=`, `*=`, `/=`

---

## **Code Snippets**

### Example 1: Arithmetic Operators
```python
a = 10
b = 3

print("Addition:", a + b)       # 13
print("Subtraction:", a - b)    # 7
print("Multiplication:", a * b) # 30
print("Division:", a / b)       # 3.333...
print("Floor Division:", a // b) # 3
print("Modulus:", a % b)        # 1
print("Exponent:", a ** b)      # 1000
```

---

### Example 2: Comparison Operators
```python
x = 5
y = 10

print(x == y)  
print(x != y)  
print(x > y)   
print(x < y)   
print(x >= 5)  # x > 5 or x == 5 => false or true = true
print(y <= 10) # y < 10 or y == 10 => false or true = true
```

---

### Example 3: Assignment Operators
```python
num = 10
num += 5   # num = num + 5
print("After += :", num) # 15

num -= 3   # num = num - 3
print("After -= :", num) # 12

num *= 2   # num = num * 2
print("After *= :", num) # 24

num /= 4   # num = num / 4
print("After /= :", num) # 6
```
